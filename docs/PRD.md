# Product Requirements Document (PRD)

## Project Title
**EstateVision 3D** - Next-Gen Interactive Real Estate Landing Page

## 1. Executive Summary
EstateVision 3D is a luxury, modern, and interactive real estate web application built using pure HTML5, CSS3, Vanilla JavaScript, Three.js, and GSAP. It provides potential home buyers and real estate investors with an immersive 3D walkthrough experience, dynamic property filtering, and interactive financial calculators without relying on heavy frontend frameworks.

## 2. Target Audience
- **High-Net-Worth Individuals (HNIs):** Looking for luxury apartments, villas, and modern residential spaces.
- **Real Estate Agencies & Builders:** Wanting a premium showcase page for prospective clients.
- **Freelance Clients/Recruiters:** Looking for advanced Vanilla JS + WebGL/3D frontend skillsets.

## 3. Tech Stack
- **HTML5:** Semantic architecture (SEO-friendly).
- **CSS3:** Custom styles, CSS Flexbox/Grid, Dark Mode Theme, Glassmorphism UI, Animations.
- **Vanilla JavaScript (ES6+):** Dynamic UI interactions, DOM manipulation, state filtering.
- **Three.js (via CDN):** 3D Model Rendering, 360-degree orbit controls, ambient lighting.
- **GSAP & ScrollTrigger (via CDN):** Scroll-based micro-interactions and high-performance UI reveals.

## 4. Key Features
1. **Interactive 3D Hero Section:** 
   - A fully renderable 3D modern house model.
   - Mouse-drag / Orbit controls to rotate and view property in 360 degrees.
2. **Property Listing & Instant Dynamic Filter:**
   - Filter properties by Price Range, BHK (1BHK, 2BHK, Villa), and Location.
   - Real-time DOM updates using Vanilla JS.
3. **Interactive EMI / Mortgage Calculator:**
   - Sliders for Principal Amount, Interest Rate, and Tenure.
   - Real-time JavaScript calculations for monthly EMI and total interest.
4. **Interactive Virtual Tour Modal:**
   - High-definition gallery and full-screen preview modals.
5. **Contact & Booking Schedule Form:**
   - Form validation, instant feedback UI, interactive calendar/time picker.

## 5. Success Metrics
- **Performance:** 90+ Lighthouse score on desktop.
- **User Engagement:** Smooth 60 FPS 3D rendering and scroll animations.
- **Responsiveness:** 100% responsive across Mobile, Tablet, and Desktop screens.
